# Ольга Лизогуб: внешний CMO, лендинг

Лендинг внешнего директора по маркетингу. Форма -> Cloudflare Worker -> Telegram (ref 27UD4AXXF6).

## Домен
Сейчас сайт на https://ollizogub.ru/ . Когда будет домен (ollizogub.ru):
1. заменить адрес `https://ollizogub.ru/` на адрес домена во всех файлах (index.html, privacy.html, materials.html, scripts.html, presentation.html, outreach.html, robots.txt, sitemap.xml). Подсказка в комментарии SITE_URL в head index.html;
2. добавить файл CNAME с доменом;
3. в Яндекс Вебмастере и Google Search Console добавить сайт и отправить sitemap.xml.

- materials.html: хаб
- scripts.html: скрипты продаж
- presentation.html: презентация для лидов (публичная, в sitemap)
